## 2. Project Description

The program is named `myls` and is designed according to the provided NetBSD 10.1 `ls` manual.

## 3. Supported Options

The following options are implemented:

- `-A` : list almost all files, excluding `.` and `..`
- `-a` : include hidden files and directories
- `-c` : use change time
- `-d` : list directories as normal files
- `-F` : classify file types with suffixes
- `-f` : do not sort output
- `-h` : display sizes in human-readable form
- `-i` : display inode number
- `-k` : display block counts in kilobytes
- `-l` : long listing format
- `-n` : long format with numeric user/group IDs
- `-q` : display non-printable characters as `?`
- `-R` : recursively list subdirectories
- `-r` : reverse sorting order
- `-S` : sort by file size
- `-s` : display filesystem block usage
- `-t` : sort by modification time
- `-u` : use access time instead of modification time
- `-w` : display non-printable characters in raw form

## 4. Intruction
./myls [op] [file]
